# 骨で解説する図（11/2 藤原さんの指示）
「肘と手根球が出っ張っていることを骨格で矢印を付けて解説を入れると分かりやすい」「他のリールやnoteも骨格単位で解説した方が分かりやすい時はそうしてほしい」
- 骨の絵は自分で描く（よその本・サイトの図をそのまま使わない）。SVG で、横から見た形を簡単に。
- 見せたい出っぱり（骨の出っぱり）に赤い矢印、黄色の点、短い札。となりに実際のワンコの写真を同じ印で並べる。
- 前肢の見本：zenshi_leg.svg.part（骨）、zenshi_note.html（note用 1280×980）、zenshi_story.html（ストーリーズ 1080×1920）。LEG の所に svg.part を入れて Playwright で撮る。
