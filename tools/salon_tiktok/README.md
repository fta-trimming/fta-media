# サロンのTikTok動画（10/24 の見本の形）

- 使い方：`python3 build.py olliemagic`（同じ場所の `<店id>.json` を読む）
- json の中の背景（bg.file）は、作業する場所に保存した材料の道すじに書きかえて使う。元の撮影写真・動画はここに置かない。
- 最後の場面は end_ollie.jpg / end_papa.jpg をそのまま使う（「最後のサロンのことは今の感じで」）。
- 1場面＝声の長さ＋約0.9秒の間。声は VOICEVOX:四国めたん（速さ1.05）。
- できたら 8MB 以下に作り直す。
- 読み方（10/24 藤原さんの指摘）：OLLIE MAGIC は「オーリーマジック」と読ませる（「オリー」ではない）。「毛」は「もう」と読まれるので、声の文では「け」とひらがなで書く。作る前に、声の文の読み（VOICEVOX の accent_phrases のカナ）を全部出して、読み間違いが無いか確かめる。
- 最後の画面の写真は、その動画に写っている子の写真にする（end_ollie.jpg の写真は 10/24 の子）。end の HTML は ol 版と同じ形（北上市の ドッグサロン・写真・ロゴ・緑のLINEボタン）で、写真だけ入れかえて作る。

## 11/2 声と言い回しの決まり（藤原さんの指示）
「横から見てもあまり丸くやまんまるなどの表現を多用しすぎ、最後の仕上がりなどだけに使うだけで良い、あまり作りすぎずシンプルに自然な言い回しで」
- 声は tts_natural.py（四国めたん・速さ1.0・抑揚1.3）。build.py が自動で使う（設定に "natural": false で前の声）。
- 声・画面の文字・投稿文は、短いシンプルな話し言葉（「〜します」「〜です」）。途中の場面は、していることをそのまま言う。
- 「まあるい」「まんまる」「ふわっふわ」などのかわいい言葉は、最後の仕上がりの場面で1回だけ。題や途中のカードでは使わない。「ほら」「〜てってください」など作った感じの言い回しは使わない。
