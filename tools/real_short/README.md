- 【11/10 藤原さん「ハサミでのカット時、前側と後ろ側がバランスよく出ていない」「ビフォーアフターのビフォーがズレている、しっかり映っていない」】ハサミの場面は前側（l_sciF）と後ろ側（l_sciB）を両方、同じくらいの長さで入れる。最後の左右くらべは、BEFORE と AFTER の両方で足の全体（腰から足先まで）が同じくらいの大きさ・位置で入るように split の bc/ac で切りぬく。見本：c12.json。元が720×1280なら W:720,H:1280 のまま作る。
- 【11/10 8:10 藤原さん「机を動かしているシーンは出ない所を使って、カットに関係ない動作は使わない」】使うのは、バリカン（アタッチメント）やハサミの刃が毛に当たって切っている所だけ。台（机）を回す・動かす所、犬を持ち直す・押さえるだけの所、手を伸ばす・道具を持ちかえる所、毛を払う所は入れない。1秒ごとのコマを並べて見て、画面の向きが急に変わる所（台を回した所）の前後を切る。長い場面は、切っている所だけを短くつないでよい（見本 c12.json）。
