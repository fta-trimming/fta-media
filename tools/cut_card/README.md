# カット中心のリール：見出しのカード（10/28 藤原さんの指示で位置を固定）

「カット中心のタイトルカードの位置が前回と今日で合ってないので、次回以降今日の位置を固定して合わせて下さい」（10/28 18:28）
→ 見本は cut/2026-10-28/reel.mp4（足裏バリカン）の 7秒ごろのカード。毎回この位置・大きさで作る。

- カード：左 45px・上 96px・幅 798px・高さ 255px（右はし 843px・下 351px）、角丸 20px、色 rgba(36,23,19,0.78〜0.93)。文字の長さで幅を変えない（1行の見出しでも同じ大きさ）。
- 小見出し（STEP 1・アタッチメントとは など）：左 80px・上 123px、30px・太字、色 #f2d06b。
- 見出し：左 80px・上 167px、60px・太字・白、行の高さ 78px、2行まで（1行15字まで）。
- 「CUT TECHNIQUE」：左 62px・上 67px ごろ、22px・白（少し透明）・字の間を広く。
- 使ったアタッチメントのカードを出すときは、カードの中の右はし（左 625〜825px・上 110〜335px）に置き、見出しは左 80〜600px に収める。
- 場面が変わってもカードは同じ場所に出したまま、中の文字だけを入れかえる。

作り方：node tools/cut_card/card.js cards.json
cards.json の例：[{"label":"STEP 1","lines":["肉球の間から","飛び出した毛を刈る"],"alpha":0.85,"out":"card1.png"}]
→ 1080×1920 の透明PNGができるので、ffmpeg の overlay で重ねる。

# はじめの縦書きタイトルカード（表紙）（10/31 藤原さんの指示で位置を固定）

「タイトルカードを前回と同じ位置に。カードの大きさは変えずに空白ができない様に文字を作る。今後もその位置で同じに」（10/31 8:56）
→ 見本は cut/2026-10-30/reel.mp4（アタッチメントの回）のはじめのカード。毎回この位置・大きさ。

- カード：左 341px・上 438px・幅 398px・高さ 1026px（右はし 739px・下 1464px）、角丸 24px、色 rgba(36,23,19,0.84)。
- 右はしに小さい列（回のテーマ・黄色 #f2d06b）、その左に大きい白い列を2列（強調は黄色）。
- 文字はどの列も上下いっぱいまで並べる（字の間を広げて、下に空きを作らない）。列はカードの幅いっぱいに広げる。
- 2列の字数はなるべくそろえる（7〜9字ずつ）。短すぎると字の間が空きすぎるので、言葉を足してそろえる。
- 作り方：node tools/cut_card/title.js title.json（{"label":"足先バリカン","cols":["<y>手の甲</y>の境目から","爪まで並で刈る"],"out":"title.png"}）→ 1080×1920 の透明PNG。はじめの2.5秒（75コマ）に重ね、表紙（cover.jpg）は1コマ目。
